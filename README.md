# Progress Digital — Central de aprovação

## Publicar o site

1. Extraia este ZIP no seu computador.
2. Crie no GitHub um repositório público chamado progress-aprovacoes.
3. Use Add file → Upload files e envie todos os arquivos e a pasta assets extraídos. O index.html deve ficar na raiz do repositório.
4. Clique em Commit changes.
5. Em Settings → Pages, escolha Deploy from a branch, branch main e pasta / (root). Clique em Save.
6. Aguarde a publicação. O endereço do site será mostrado nessa página.

## Uso

Adicione imagens, legendas ou roteiros, confira a prévia e baixe o PDF. Os materiais ficam apenas na sessão aberta do navegador. Não há armazenamento de conteúdo de clientes no servidor.
